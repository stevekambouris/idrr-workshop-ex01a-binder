### An introduction to using Docker with R for reproducible research
# Example: Summarising the penguins data set (R 3.6.0)

_This repository is set up to be launched as a container on <mybinder.org>, rather than to be used to build an image with Docker Desktop. For the version of this example that can be used to build an image locally, go to <https://github.com/stevekambouris/idrr-workshop-ex01a>._

Click the button below to start an instance of the container defined by this repository on mybinder.org.

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/stevekambouris/idrr-workshop-ex01a-binder/main?urlpath=rstudio)

This Docker image is based on rocker/binder:3.6.0, which has R version `3.6.0` installed, along with `tidyverse` packages (and in particular, `dplyr` version `0.8.3`).
